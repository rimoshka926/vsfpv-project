# Changelog

## 1.4 - 2026-10-12

- An armed PG-7 no longer goes off when it flies out of the loaded area
- With Universal PVP, a PG-7 that blows up next to its own pilot now hurts the pilot too
- In multiplayer the server only takes flight input from the player sitting at the transmitter
- Script cleanup, nothing else changes in game

## 1.3 - 2026-09-28

- Mouse wheel controls throttle on the PG-7 and DJI FPV, 1% per notch. The Mavic still uses it for zoom

## 1.2 - 2026-09-26

- Analog video look on the PG-7 camera: grain, interference that gets worse with throttle, the odd rolling glitch, and static when the drone is gone
- THROTTLE label on the OSD

## 1.1 - 2026-09-25

- Mouse forward pitches the nose down on the PG-7 and DJI FPV, like a radio. Key 7 switches back to the old way
- Hiding the controls list with 9 is remembered for each type of drone

## 2026-09-18

- Moved to a new Workshop item, the old one was deleted

## 2026-09-17

- Artificial horizon and a reticle on the PG-7 camera
- Horizon lock on the Mavic, key 6
- White OSD text
- Propane tanks in the jet's path now explode instead of disappearing
- The Mavic no longer drifts or speeds up when flying diagonally

## 1.0 - 2026-09-06

- First release: DJI FPV, Mavic 3 Cine and PG-7 Kamikaze, flown from the FPV Transmitter
